DETALLES TÉCNICOS
================================================================================

COMBOBOX FILTRABLE - CÓMO FUNCIONA:
- Campo: combo_producto (Combobox)
- Evento: KeyRelease (cuando escribes)
- Función: _filtrar_combo_productos()
- Lógica:
  1. Al escribir, captura el texto
  2. Filtra lista completa por ese texto
  3. Actualiza valores del combobox en tiempo real
  4. Si vacío, muestra todos los productos

DETECCIÓN DE DUPLICADOS:
- Similitud >= 80% = Se considera duplicado
- Si detecta:
  * Opción 1 (SÍ): Redirige a Movimientos + preselecciona producto
  * Opción 2 (NO): Cancela adición, mantiene datos en formulario
- Formato del mensaje: Claro y explicativo

LIMPIEZA EXCEL:
- Mantiene: Estructura de hojas, encabezados, formateo
- Elimina: Todos los datos de filas
- Elimina: Hoja "Reportes" completa
- Resultado: Base de datos limpia pero funcional

CÓMO USAR LOS CAMBIOS
================================================================================

PARA USAR EL COMBOBOX FILTRABLE:
1. Abre la pestaña "↔️ Movimientos"
2. En el campo "Producto", haz clic para ver todos
3. Escribe para filtrar (busca por ID o nombre)
4. Selecciona de la lista desplegable

PARA DETECTAR DUPLICADOS:
1. Intenta agregar un producto similar a uno existente
2. Si se detecta, verás el diálogo
3. Presiona "SÍ" para ir a movimientos
4. Presiona "NO" para cancelar (datos se mantienen)

PARA LIMPIAR LA BD:
Opción 1 - Automática (recomendada):
1. Abre línea de comandos en la carpeta del programa
2. Ejecuta: python limpiar_excel.py
3. Listo - BD limpia

Opción 2 - Manual:
1. Abre data/almacen.xlsx en Excel
2. Elimina filas de datos (mantén encabezados)
3. Elimina hoja "Reportes"
4. Guarda
