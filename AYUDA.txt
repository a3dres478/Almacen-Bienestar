INFORMACION DE CONTACTO Y SOPORTE

Si tienes preguntas o problemas:

1. Verifica que hayas seguido los pasos correctamente
2. Lee la sección Troubleshooting de GUIA_INICIO.txt
3. Verifica que Python esté correctamente instalado
4. Ejecuta INSTALAR.bat para reinstalar dependencias
5. Si el problema persiste, documenta:
   - ¿Qué intentaste hacer?
   - ¿Qué error recibiste? (captura de pantalla)
   - ¿Qué sistema operativo usas?

Información técnica útil:
  - Versión de Python: python --version
  - Paquetes instalados: pip list
  - Error exacto: copia el mensaje completo
