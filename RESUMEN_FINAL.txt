  • Campo adicional en productos
  • Para agregar evidencia visual
  • Se guarda en la base de datos
  • Ver imagen desde detalles del producto

📋 DETALLES COMPLETOS:
  • Doble click en producto → ventana emergente
  • Muestra TODA la información
  • Incluye fecha de creación
  • Botón "Ver Imagen" si hay URL

✅ VALIDACIONES MEJORADAS:
  • Stock: solo números enteros ≥ 0
  • Precio: números decimales ≥ 0
  • Cantidad: solo enteros positivos
  • Mensajes de error claros y específicos
  Fondo           #f1f8e9    ← Fondo general
  Texto           #1b5e20    ← Verde oscuro

CREAR EJECUTABLE PORTABLE - OPCIONAL
================================================================================

Si quieres distribuir la aplicación sin que el usuario instale Python:

OPCION 1: Automática
  1. Haz doble click en: CREAR_EJECUTABLE.bat
  2. Espera 2-3 minutos
  3. Se creará: dist/GestorAlmacenes.exe

OPCION 2: Línea de comandos
  1. Abre Command Prompt en la carpeta App
  2. Ejecuta: CREAR_EJECUTABLE.bat

RESULTADO:
  - Un archivo: dist/GestorAlmacenes.exe (~100-150 MB)
  - Usuario hace doble click
  - Aplicación se abre directamente
  - ¡Sin necesidad de Python!

================================================================================
COMO USAR LA BASE DE DATOS - IMPORTANTE
================================================================================

UBICACION: data/almacen.xlsx

CONTIENE 3 HOJAS:
  1. Productos
     - Registro de todos los productos
     - Columnas: ID, Nombre, Descripción, Stock, Precio, Unidad

  2. Movimientos  
     - Historial completo de entradas/salidas
     - Columnas: ID, Fecha, Tipo, Producto, Cantidad, Stock Anterior/Nuevo, Motivo, Responsable

  3. Reportes
     - Resumen generado automáticamente
     - Se especifica al generar reporte

IMPORTANTE:
  ✓ Usar la aplicación para registrar movimientos (mejor)
  ✓ No abrir Excel mientras la app está corriendo
  ✓ Hacer backup regularmente (copiar data/almacen.xlsx)
  ✓ Si necesitas editar, cierra la app y abre en Excel

================================================================================
HACE BACKUP - MUY IMPORTANTE
================================================================================

Dos formas de respaldar:

OPCION 1: Manual (cada semana)
  1. Navega a: data/almacen.xlsx
  2. Copia el archivo
  3. Pégalo en: Google Drive, USB, otra carpeta

OPCION 2: Automático (desde la app)
  1. Pestaña "Reportes"
  2. Click "Exportar a Excel"
  3. Elige dónde guardar (va a una copia nueva)

RECOMENDACION: Haz backup AL MENOS una vez por semana

================================================================================
SEGURIDAD Y LIMITACIONES
================================================================================

SEGURIDAD:
  ✓ Validación de entrada de datos
  ✓ Manejo de errores robusto
  ✓ No se pueden borrar registros (solo agregar)
  ✓ Historial completo para auditoría
  ✓ Responsable registrado en cada movimiento

LIMITACIONES:
  ✗ Sin autenticación de usuarios (confía en responsables)
  ✗ Sin encriptación (almacén pequeño y privado)
  ✗ Sin control de acceso (todos pueden usar por igual)
  ✗ Asincrónico (no tiempo real)
  ✗ Óptimo hasta 100,000 registros

IDEAL PARA:
  - Almacenes pequeños (10-1000 productos)
  - Equipos pequeños (2-10 personas)
  - Entorno de confianza
  - Uso no crítico

NO IDEAL PARA:
  - Almacenes muy grandes
  - Múltiples usuarios simultáneos
  - Entornos de alta seguridad
  - Sistemas tiempo-real

EJEMPLOS DE USO
================================================================================

EJEMPLO 1: Compra de stock
  1. Recibes mercancía con factura
  2. Pestaña Movimientos
  3. Selecciona producto, Tipo "Entrada"
  4. Cantidad: la cantidad recibida
  5. Motivo: "Compra Factura ABC123"
  6. Responsable: tu nombre
  7. Click "Registrar Movimiento"
  8. ¡Stock actualizado automáticamente!

EJEMPLO 2: Venta a cliente
  1. El cliente compra, generas factura
  2. Pestaña Movimientos
  3. Selecciona producto, Tipo "Salida"  
  4. Cantidad: la cantidad vendida
  5. Motivo: "Venta Factura XYZ789"
  6. Responsable: tu nombre
  7. Stock disminuye automáticamente

EJEMPLO 3: Importar muchos productos
  1. Pestaña Importar/Exportar
  2. Click "Descargar Plantilla"
  3. Completa en Excel con tus productos
  4. Guarda el archivo
  5. Click "Seleccionar Archivo"
  6. Elige el Excel que completaste
  7. Todos los productos se agregan de una vez

EJEMPLO 4: Generar reporte mensual
  1. Fin del mes, Pestaña Reportes
  2. Click "Generar Reporte Completo"
  3. Ves resumen de todos los productos
  4. Click "Exportar a Excel"
  5. Guarda con nombre: "Reporte_Almacen_Abril_2026.xlsx"
  6. Tienes respaldo del mes
