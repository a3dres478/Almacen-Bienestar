La carpeta debe contener:
- Archivo: INICIAR.bat (para abrir el sistema)

✓ NO debes mover ni cambiar el nombre de estos archivos

3. Listo para usar

PESTAÑA 1: AGREGAR PRODUCTOS (📦 Productos)
================================================================================
¿Qué hacer aquí?
- Agregar nuevos productos al almacén

PASOS:
1. Rellena los campos:
   - Nombre: Nombre del producto (Ej: Tijeras, Destornillador)
   - Descripción: Detalles del producto (Ej: Color rojo, tamaño grande)
   - Stock Inicial: Cantidad que tienes ahora (Ej: 10)
   - Unidad Medida: Selecciona una opción:
     * Unidades (para cosas individuales)
     * Kg (para cosas que pesas)
     * Otro (para otras medidas)
   - URL Imagen (opcional): Link de imagen del producto

2. Haz clic en "✅ Agregar Producto"

3. Si el sistema detecta un producto muy parecido:
   - Te preguntará si quieres crear uno nuevo o registrar movimiento en el existente
   - Si es el mismo producto, haz clic en SÍ → va directamente a Movimientos

IMPORTANTE:
- Los nombres se formatean automáticamente (Ej: "tijeras" → "Tijeras")
- Los nombres con mayúsculas/minúsculas se normalizan


PESTAÑA 2: REGISTRAR MOVIMIENTOS (➕➖ Movimientos)
================================================================================
¿Qué hacer aquí?
- Registrar entradas (cuando compras) o salidas (cuando vendes/usas) de productos

PASOS:
1. Selecciona el producto:
   - En "Seleccionar Producto" elige de la lista (Ej: "1 - Tijeras")

2. Elige el tipo de movimiento:
   - "Entrada" = Acabas de recibir/comprar el producto
   - "Salida" = Vendiste/usaste el producto

3. Ingresa la cantidad:
   - Número entero sin decimales (Ej: 5, 10, 100)
   - OBLIGATORIO: Debe ser mayor a 0

4. Ingresa el motivo:
   - Por qué entra o sale (Ej: "Compra a proveedor", "Venta cliente XYZ")
   - OBLIGATORIO: No puede estar vacío

5. Ingresa el responsable:
   - Tu nombre o quien hizo el movimiento (Ej: "Julito", "Juan")
   - Puede estar vacío si no quieres completarlo

6. Haz clic en "✅ Registrar"

EJEMPLO:
- Producto: 1 - Tijeras
- Tipo: Entrada
- Cantidad: 50
- Motivo: Compra a proveedor ABC
- Responsable: Julito
→ Resultado: Se suman 50 tijeras al stock


PESTAÑA 3: VER HISTORIAL (📋 Historial)
================================================================================
¿Qué hacer aquí?
- Ver todos los movimientos que hiciste (entradas y salidas)

OPCIÓN 1 - Ver movimientos de UN PRODUCTO:
1. En "Seleccionar Producto", elige el producto
2. Haz clic en "🔍 Ver Historial"
3. Verás solo los movimientos de ese producto

OPCIÓN 2 - Ver TODOS los movimientos:
1. Haz clic en "🔄 Todos"
2. Verás todo el historial completo

OPCIÓN 3 - Buscar por RANGO DE FECHAS:
1. En "Buscar por Rango de Fechas", completa:
   - Desde: Fecha inicial (formato: DD/MM/YYYY - Ej: 01/01/2025)
   - Hasta: Fecha final (formato: DD/MM/YYYY - Ej: 31/12/2026)
2. Haz clic en "🔎 Buscar por Fecha"
3. Verás solo los movimientos en ese rango

EJEMPLO:
- Desde: 01/04/2026
- Hasta: 17/04/2026
- Resultado: Todos los movimientos de abril 2026

QUÉ VES EN LA TABLA:
- Fecha: Cuándo se hizo el movimiento
- Mes/Año: Mes y año del movimiento
- Tipo: Entrada o Salida
- Producto: Nombre del producto
- Cantidad: Cuántas unidades entraron/salieron
- Stock Anterior: Stock antes del movimiento
- Stock Nuevo: Stock después del movimiento
- Motivo: Por qué se hizo
- Responsable: Quién lo registró


PESTAÑA 4: GENERAR REPORTES (📊 Reportes)
================================================================================
¿Qué hacer aquí?
- Ver resumen total del almacén
- Exportar datos a Excel

OPCIÓN 1 - Ver reporte en pantalla:
1. Haz clic en "📊 Ver Reporte"
2. Verás el resumen completo:
   - Total de productos
   - Total de movimientos
   - Detalles de cada producto

OPCIÓN 2 - Descargar plantilla para cargar productos:
1. Haz clic en "📥 Descargar Plantilla"
2. Te pide dónde guardar el archivo
3. Completa el Excel con los productos
4. Importa el archivo desde la pestaña "Importar"

OPCIÓN 3 - Exportar todo a Excel:
1. Haz clic en "💾 Exportar a Excel"
2. Te pide dónde guardar el archivo
3. Se descarga una copia de la BD con todos los datos


PESTAÑA 5: IMPORTAR DATOS (📥 Importar)
================================================================================
¿Qué hacer aquí?
- Cargar muchos productos de una vez desde Excel

PASOS:
1. Haz clic en "📥 Descargar Plantilla" en la pestaña Reportes
2. Completa el Excel con tus productos
3. Vuelve a esta pestaña (Importar)
4. Haz clic en "Seleccionar Archivo"
5. Elige el Excel que completaste
6. Haz clic en "📥 Importar"
7. Listo - Los productos se agregarán al sistema

ERRORES COMUNES Y SOLUCIONES
================================================================================
❌ "Debe seleccionar producto y tipo de movimiento"
   → Asegúrate de seleccionar un producto y elegir Entrada o Salida

❌ "La cantidad debe ser un número entero mayor a 0"
   → Ingresa solo números sin decimales, y que sea mayor a 0
   → Ej: Está bien "5", no está bien "5.5" o "0"

❌ "El motivo es obligatorio"
   → Completa el campo "Motivo" antes de registrar

❌ "El nombre del producto es obligatorio"
   → Rellena el campo "Nombre" al agregar un producto

❌ "Error al conectar a la base de datos"
   → Cierra el programa y vuelve a abrirlo
   → Si persiste, verifica que el archivo "almacen.xlsx" esté en la carpeta "data"

PREGUNTAS FRECUENTES
================================================================================

P: ¿Puedo usar el programa sin internet?
R: SÍ. El programa funciona completamente sin internet. 
   Internet solo es necesario si quieres ver imágenes de los productos.

P: ¿Dónde se guardan mis datos?
R: En la carpeta llamada "data" dentro de la carpeta del programa.
   El archivo se llama "almacen.xlsx" (es un Excel).

P: ¿Qué pasa si cierro el programa sin guardar?
R: Los datos se guardan AUTOMÁTICAMENTE. No necesitas hacer nada especial.
   Cada movimiento se guarda inmediatamente.

P: ¿Puedo cambiar o eliminar un producto?
R: Por ahora NO. El sistema no permite editar ni eliminar.
   Si cometiste un error, contacta al administrador.

P: ¿Cuántos productos puedo agregar?
R: Sin límite. El sistema puede manejar miles de productos.

P: ¿Qué hago si se congela el programa?
R: Ciérralo y vuelve a abrir. Los datos están guardados.
   Si sigue congelado, reinicia tu PC.

P: ¿Puedo ver el historial completo desde el principio?
R: No. Se limpió el historial anterior a abril 2026.
   Ahora tienes historial limpio desde el 17 de abril de 2026.

P: ¿Cómo hago un respaldo de mis datos?
R: Ve a la pestaña "Reportes" → "Exportar a Excel"
   Eso crea una copia de tu base de datos.

P: ¿Puedo trabajar varias personas a la vez?
R: No. Un solo usuario puede usar el programa a la vez.
   Si otro intenta abrir, tendrá problemas.


MANTENIMIENTO DE DATOS
================================================================================

HACER UN RESPALDO (BACKUP)
Es importante hacer copias de seguridad regularmente:

1. Abre el Gestor de Almacenes
2. Ve a la pestaña "📊 Reportes"
3. Haz clic en "💾 Exportar a Excel"
4. Elige una carpeta donde guardar (Ej: Mi Computadora → Escritorio)
5. Dale un nombre con la fecha (Ej: Backup_17_04_2026.xlsx)
6. Guarda el archivo

RECOMENDACIÓN: Haz un respaldo cada fin de mes

BUSCAR EN EL HISTORIAL ANTIGUO
Si necesitas ver movimientos de meses anteriores:
1. Ve a la pestaña "📋 Historial"
2. Usa "Buscar por Rango de Fechas"
3. Ingresa las fechas que necesitas (formato DD/MM/YYYY)
4. Verás todos los movimientos de esa época

VERIFICAR STOCKS
Para saber cuánto tienes de cada cosa:
1. Ve a la pestaña "📦 Productos"
2. Mira la columna "Stock" en la tabla
3. Para más detalles, haz DOBLE CLIC en el producto

SOLUCIÓN DE PROBLEMAS AVANZADA
================================================================================

PROBLEMA: El archivo INICIAR.bat no funciona
SOLUCIÓN:
1. Ve a la carpeta del programa
2. Haz clic DERECHO sobre INICIAR.bat
3. "Propiedades" → "Compatibilidad"
4. Marca "Ejecutar este programa en modo de compatibilidad"
5. Elige "Windows 7"
6. Aplica y prueba

PROBLEMA: No abre nada al hacer doble clic
SOLUCIÓN:
1. Descarga Python desde https://www.python.org
2. Instala Python 3.7 o superior
3. IMPORTANTE: Marca "Add Python to PATH" durante instalación
4. Reinicia el PC
5. Ahora intenta abrir el programa

PROBLEMA: Dice "No se encontró el archivo almacen.xlsx"
SOLUCIÓN:
1. Abre el Bloc de Notas
2. Copia esto:
   [En blanco - esto crea la base de datos automáticamente]
3. Abre el Gestor de Almacenes nuevamente
4. Se creará la base de datos automáticamente

PROBLEMA: Los datos no se guardan
SOLUCIÓN:
1. Cierra el programa
2. Verifica que la carpeta "data" exista
3. Verifica que tengas permisos de escritura en la carpeta
4. Abre el programa nuevamente
