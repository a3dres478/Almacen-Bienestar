================================================================================
REQUISITOS DEL LOGO
================================================================================

Para que el logo se vea bien:

FORMATO:           PNG (o .jpg al cual se le convertirá a PNG)
NOMBRE:            logo.png (exactamente este nombre)
UBICACION:         Carpeta App (junto a main.py)
TAMAÑO:            700x700 píxeles o mayor (se redimensiona automáticamente)
PROPORCION:        Preferentemente cuadrado (si no es cuadrado se ajusta)
COLORES:           Cualquier color (verde es lo natural para el cocodrilo)
FONDO:             Puede tener fondo transparente o sólido
CALIDAD:           Mínimo 200x200 píxeles (se verá pequeño en la app)

================================================================================
TAMAÑO EN LA APLICACION
================================================================================

El logo se mostrará con estos tamaños:

PANTALLA:          Se redimensiona a 60x60 píxeles en el encabezado
INTERFAZ:          Ocupa el lado izquierdo del encabezado verde oscuro
PROPORCION:        Se mantiene la proporción del original

Si tu imagen es cuadrada (500x500):
  └─ Se mostrará como cuadrado de 60x60 ✓

Si tu imagen es rectangular (800x400):
  └─ Se ajusta manteniendo proporción ✓

================================================================================
SOLUCCION DE PROBLEMAS CON EL LOGO
================================================================================

PROBLEMA                          SOLUCION
─────────────────────────────────────────────────────────────────────────────

El logo no aparece                1. Verifica que logo.png esté en la carpeta
                                  2. Cierra y abre nuevamente INICIAR.bat
                                  3. Ejecuta INSTALAR.bat para reinstalar Pillow

"No se pudo cargar el logo"       1. El archivo no es PNG válido
(en pantalla de error)            2. Usa convertir_logo.py para convertir
                                  3. Verifica que la imagen no esté dañada

El ejecutable no incluye el logo  1. Logo debe estar en la carpeta antes de crear .exe
                                  2. Ejecuta CREAR_EJECUTABLE.bat de nuevo
                                  3. Verifica que logo.png exista

Logo se ve pixelado               1. La imagen es muy pequeña
                                  2. Usa una imagen de al menos 500x500
                                  3. Mejor: 1000x1000 píxeles

Logo se ve deformado              1. Si la imagen no es cuadrada
                                  2. El script intentará mantener proporción
                                  3. Usa imagen cuadrada para mejor resultado
