================================================================================
QUE ES ESTO?
================================================================================

Un GESTOR DE ALMACEN (Warehouse Manager) que:

  ✓ Gestiona tu inventario
  ✓ Registra entrada y salida de productos
  ✓ Calcula stock automáticamente
  ✓ Genera reportes
  ✓ Exporta a Excel
  ✓ Tiene interfaz verde profesional
  ✓ Funciona sin internet
  ✓ Guarda datos en Excel (puedes editar manualmente si quieres)

================================================================================
CARACTERISTICAS PRINCIPALES
================================================================================

5 PESTAÑAS FUNCIONALES:

1. PRODUCTOS
   ├─ Agregar nuevos productos
   ├─ Ver stock de cada uno
   ├─ Información: nombre, descripción, precio, unidad
   └─ Visualizar en tabla

2. MOVIMIENTOS
   ├─ Registrar entrada de productos (Compra)
   ├─ Registrar salida de productos (Venta)
   ├─ Stock se actualiza automáticamente
   ├─ Motivo y responsable
   └─ Histórico de últimos movimientos

3. HISTORIAL
   ├─ Ver TODOS los movimientos
   ├─ Stock antes y después
   ├─ Filtrar por producto
   ├─ Fecha, hora, responsable completo
   └─ Trazabilidad completa

4. REPORTES
   ├─ Generar resumen automático
   ├─ Entradas y salidas totales por producto
   ├─ Stock actual
   ├─ Valor total del inventario
   └─ Exportar a Excel

5. IMPORTAR/EXPORTAR
   ├─ Descargar plantilla Excel
   ├─ Importar datos en lote
   ├─ Exportar base de datos completa
   └─ Integración con Excel total

PREGUNTAS FRECUENTES
================================================================================

P: ¿Necesito internet?
R: No. Todo funciona offline. Excel almacena datos localmente.

P: ¿Puedo usar en Excel directamente?
R: Sí. Los datos están en data/almacen.xlsx. Puedes editar manualmente.

P: ¿Puedo tener más de un usuario?
R: Sí. Diferentes personas pueden registrar sus movimientos.

P: ¿Qué pasa si dejo la app abierta?
R: Nada. Los datos se guardan automáticamente en Excel después de cada acción.

P: ¿Puedo tener miles de productos?
R: Sí. La app escala bien. Excel puede manejar cientos de miles.

P: ¿Cómo respaldo mis datos?
R: Simplemente copia data/almacen.xlsx a otro lugar (USB, cloud).

P: ¿Puedo dar el .exe a otros?
R: Sí. Ejecuta CREAR_EJECUTABLE.bat y distribuye dist/GestorAlmacenes.exe.

P: ¿Necesitan Python los otros?
R: No. El .exe es standalone.

P: ¿Puedo modificar el código?
R: Sí. Es código Python, puedes modificar main.py y database.py.

P: ¿Puedo agregar más funciones?
R: Sí. Ver ARQUITECTURA.txt para guía de desarrollo.
