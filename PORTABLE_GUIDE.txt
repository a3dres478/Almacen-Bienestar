COMO USAR
================================================================================

PASO 1: INSTALAR DEPENDENCIAS (una sola vez)
  Haz doble click en: INSTALAR.bat
  Esto instala openpyxl y Pillow

PASO 2: AGREGAR LOGO (opcional)
  - Opción A: Coloca logo.png en la carpeta App
  - Opción B: Haz doble click en convertir_logo.py si la imagen está en otro formato

PASO 3: EJECUTAR LA APLICACION
  Haz doble click en: INICIAR.bat
  ¡O simplemente ejecuta: python main.py

PASO 4: CREAR EJECUTABLE (opcional, para distribuir)
  Haz doble click en: CREAR_EJECUTABLE.bat
  Se creará dist/GestorAlmacenes.exe (archivo portable)

================================================================================
COMO CREAR EJECUTABLE PORTABLE
================================================================================

Hay 2 formas:

OPCION 1: Automática (recomendado)
  1. Abre CREAR_EJECUTABLE.bat
  2. Espera a que termine (puede tomar 2-3 minutos)
  3. El ejecutable estará en: dist/GestorAlmacenes.exe

OPCION 2: Manual (si OPCION 1 no funciona)
  1. Abre Command Prompt
  2. Navega a la carpeta App
  3. Ejecuta:
     pip install pyinstaller
     pyinstaller --onefile --windowed --name=GestorAlmacenes ^
         --hidden-import=openpyxl --hidden-import=PIL ^
         --add-data "data;data" --add-data "templates;templates" ^
         --add-data "logo.png;." main.py
  4. Encontrarás el .exe en: dist/GestorAlmacenes.exe

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEMA: El logo no aparece
SOLUCION:
  1. Verifica que logo.png esté en la carpeta App
  2. Verifica que sea formato PNG
  3. Reinstala Pillow: pip install --upgrade Pillow
  4. Reinicia INICIAR.bat

PROBLEMA: CREAR_EJECUTABLE.bat no funciona
SOLUCION:
  1. Abre Command Prompt como administrador
  2. Navega a la carpeta App
  3. Ejecuta: pip install pyinstaller
  4. Intenta nuevamente CREAR_EJECUTABLE.bat

PROBLEMA: El ejecutable es demasiado grande
EXPLICACION:
  Es normal. PyInstaller empaqueta Python + todas las librerías (100-150 MB)

PROBLEMA: El ejecutable tarda en abrir
EXPLICACION:
  Es normal la primera vez. Luego se cachea y es más rápido.
